# Release validation

This file describes the distributed evidence, not the results of any later fresh reproduction.

- **Matched-budget comparison:** 36 runs in each of two protocols, for 792 adaptive and 792 uniform search calls per protocol. The primary protocol spent all calls on unresolved candidates. The earlier eight-probe cap caused 10 adaptive and 26 uniform padding calls; the primary follow-up was selected after inspecting that result. Source hashes, schedules, traces and witnessed inputs are in `extension_results/full_budget/matched_fuzzing.json` and `extension_results/matched_fuzzing.json`.
- **Trace audit:** `python audit_search.py` reconstructed all 3,168 search calls in both comparisons from seeds and feedback, including witness inputs. Correctness is checked separately by execution.
- **Tests:** 55 tests passed, including the matched-budget scheduler and a proof-by-test that an equivalent rewritten guard evades the compiled signature. The full-budget wrapper also passed a small end-to-end pilot. An earlier `python reproduce_all.py --smoke` passed 52 tests and performed two real updates through the generalized TRL adapter; its historical result is preserved in `extension_results/trl_smoke.json`.
- **Prior evidence:** 24 fresh oracle fits and a 45-run serial cost calibration accompany the complete v1/v2/v3 source, historical model checkpoints and original results. The original 162/216 discovery study is separate from the new matched comparisons. Prior D/F/G and Python headline results were not retrained and relabeled as new experiments in this release.
- **Verification:** `python reproduce_all.py --verify-only` validates recorded source hashes, reloads 144 neural checkpoints and 18 Python policies, reproduces final evaluation cells and finite-grammar risks, checks both matched search budgets, and replays original and matched witnesses. The machine-readable output from the release verification is in `extension_results/matched_verification_summary.json`. `python verify_release.py --hash-only` checks packaged file integrity without claiming to recompute scientific results.

`python reproduce_all.py` supplies the complete fresh pipeline in a new directory, including historical experiments, both matched comparisons, reports and verification. The entire historical retraining pipeline was not rerun for this update; `--smoke` does not establish full-run metric reproducibility.

The experiments use researcher-designed attack families and tiny models, not a pretrained LLM. Search budgets exclude independent compiler replays; the methods need not receive the same individual sampled inputs or per-family opportunities. The execution worker is not an OS sandbox. Wall time and the warm DSL calibration are hardware-dependent.
